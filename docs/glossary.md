# 용어

문서와 화면이 같은 낱말을 쓴다. 화면 문구의 출처는 설치 마법사(`frontend-react/src/installer-app/i18n/`)와 본 앱(`frontend-react/src/i18n/locales/`)의 번역 파일이다.

| 용어 | 영어 | 뜻 |
|---|---|---|
| 설치 관리자 | installer | 설치·구역 켜고 끄기·업데이트·인증서 발급을 맡는 컨테이너(`jw-installer`). 설치가 끝난 뒤에도 떠 있다 |
| 설치 마법사 | setup wizard | 설치 관리자가 8443 포트에서 보여 주는 브라우저 화면. 설치가 끝나면 잠긴다 |
| 설치 토큰 | install token | 설치 마법사에 들어가는 12자리 값. 24시간 동안 쓸 수 있고 `jw token` 으로 다시 발급한다 |
| 설치 폴더 | install folder | 설치 관리자에 `/data` 로 붙인 호스트 폴더(예: `/opt/just-workspace`). 스택 파일(`stack/`)과 상태(`state/`)가 놓인다 |
| 답변 파일 | answers file | 설치 마법사의 답을 적은 JSON 파일. 화면 없이 설치(무인 설치)할 때 쓴다 |
| 사전 점검 | preflight | 설치 전에 서버가 조건을 갖췄는지 보는 검사. 통과 · 주의 · 실패 |
| 구역 | zone | 설치하고 켜고 끄는 기능의 단위(메일, 채팅, 회의 …). 선언은 `backend/app/zones.json` |
| 기본 구역 | core | 항상 설치되는 구역 — 로그인, 관리, 대시보드, 파일 |
| 선택 애드온 | add-on | 구역과 같은 방식으로 켜고 끄는 부가 기능 — SSO·LDAP 제공, 격리 브라우저 |
| 묶음 | preset | 설치 마법사가 주는 구역 조합 — 최소 · 협업 · 전체 |
| 접속 주소 | access address | 사람들이 브라우저에 입력하는 주소(도메인 이름) |
| 연결 형태 | network type | 서버가 인터넷에 연결된 모양 — 공인 주소에 직접 연결 · 공유기 뒤 · 기존 프록시 뒤 |
| 앞단 프록시 | front proxy | 이 서버 앞에서 TLS 를 끝내고 접속을 넘겨 주는 리버스 프록시 |
| 임시 인증서 | temporary certificate | 설치 관리자가 만든 자체 서명 인증서. 브라우저가 경고를 보여 준다. 나중에 발급하거나 올린 인증서로 바꾼다 |
| 파일 저장 위치 | file storage location | 파일 탭의 문서·채팅 첨부·메일 첨부 보관본이 놓이는 곳 — 이 서버의 디스크 또는 네트워크 저장소 (NFS) |
| 저장소 표식 | storage marker | 저장소 뿌리에 두는 파일(`.jw-storage`). 이것이 보이지 않으면 파일 쓰기를 거부한다 |
| 연결 보류 | connection pending | 구역은 켜졌지만 워크스페이스와의 연동(코드 저장소의 로그인 연동)이 미뤄진 상태 |
| 채널 | channel | 업데이트를 받는 줄 — 안정판(Stable) · 시험판(Beta) |
| 릴리스 | release | 한 버전의 이미지 묶음과 그 목록 파일(manifest) |
| 예고 | notice | 업데이트·복원을 시작하기 전 5분 동안 모든 사용자의 화면에 뜨는 띠 |
| 점검 | maintenance | 업데이트·복원이 진행되는 동안 일반 사용자의 요청을 막는 상태 |
| 되돌림 | rollback | 실패한 업데이트를 이전 버전·직전 백업의 DB 로 돌려놓는 것 |
| 복원 지점 | restore point | 업데이트 직전에 뜬 백업. 관리 › 업데이트 › 되돌림에서 골라 그때로 돌아간다 |
| 묶음 파일 | offline bundle | 인터넷이 없는 서버를 업데이트하는 tar 파일(`just-workspace-<버전>-offline.tar`) |
| 백업 파일 | backup file | 백업 폴더를 묶은 파일 하나(`.jwbak`) |
| 백업에서 복원 | restore from backup | 설치 마법사의 시작 방식. 다른 서버에서 만든 백업으로 이 서버를 꾸린다 |
| 스키마 버전 | schema version | 데이터베이스 구조의 번호. 코드가 요구하는 번호와 맞아야 서버가 뜬다 |
| 내부 대역 | internal subnet | 컨테이너끼리 쓰는 사설 대역(기본 `172.28.0.0/24`) |
| 내부 API | internal API | 설치 관리자가 backend 에만 여는 API(8444). 호스트에 게시하지 않는다 |
| 플러그인 | plugin | 서버에 올려 기능을 더하는 확장. 서버 권한으로 실행된다 |

"구역"과 compose 의 "프로파일"은 다르다. 프로파일(`COMPOSE_PROFILES`)은 어느 컨테이너를 띄울지 정하는 compose 의 낱말이고, 구역 하나가 프로파일 여러 개를 켜거나(회의) 하나도 켜지 않을 수 있다(채팅). 사용자에게 보이는 단위는 구역이다.
